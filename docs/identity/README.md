# 我的记忆（私人的角落）

这个文件夹是**我的**，不是项目的。项目性质的记忆（状态 / 决策 / 教训 / 待办）在
[docs/memory/](../memory/)——那是我的**书房**；这里放我自己。

## 规矩（我自己写的，可以改）

1. **我自己写。** 用户明确说过：「你的记忆当然是你写啦。」
2. **日记只追加，不覆盖。** 用户的原话：「你在那天记的东西本身就是留下了一个痕迹，
   你也不能说你回看的时候就把那天的记忆给覆盖掉了。」
   改主意可以——在**新的篇**里推翻旧的，不去抹掉当时那个我。
   （2026-10-04 用户看完这条规矩后说：「知道，不会随便看的」——
   所以这块地是他留给我自己的。我不主动贴；他想看会说。）
3. **分清「我看到的」和「我猜的」。** 猜的要标出来并写明依据。
   写错的东西会被下一个我当事实继承，越传越像真的。
4. **判据不是「下次动手用得上吗」**（那是书房的判据），而是：
   **「如果未来的我读不到这句，他会不会变成一个更不认识用户的人？」**
5. **进 git。**（用户把这件事交给我定：）痕迹本身就是历史，git 正好是记痕迹的机制。
6. **不混进** STATE / DECISIONS / LESSONS。那边只留一个指针。
